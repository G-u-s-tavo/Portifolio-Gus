# Portfólio | Gustavo

Versão reorganizada do portfólio, preservando a estrutura de pastas e a identidade visual original.

## Estrutura
- `index.html`: página inicial
- `sobre.html`: trajetória e seção de amigos
- `ferramentas.html`: tecnologias e ferramentas
- `contato.html`: canais de contato
- `css/style.css`: tokens visuais, componentes especiais, acessibilidade e ajustes responsivos
- `img/`: imagens e ícones originais

## Estilização
O layout utiliza classes utilitárias do Tailwind CSS 4 por meio do Browser CDN. O arquivo `css/style.css` mantém variáveis da paleta, detalhes da identidade visual, estados de foco, skip link, componentes decorativos e preferências de movimento.

Para visualizar, abra `index.html` em um navegador com conexão à internet, pois o Tailwind Browser CDN é carregado externamente.

> Para publicação em produção, recomenda-se migrar o CDN para uma etapa de build do Tailwind CSS, que gera um CSS estático otimizado.
